# Recursive composition canvas prototype

Standalone React Flow playground, separate from Langflow. Includes the component catalog, proposed reusable layers, hover trays, and the current hypothetical confederation collaboration diagram. Entries above components are design proposals, not executable implementations.

## Run

From `frontend`, install dependencies with `npm ci`, then run `npm run dev`. Open `/prototype-canvas/` on the address printed by Vite.

The current diagram is preserved in `current-diagram.js` and displayed in `main.jsx`. An earlier example is preserved in `market-growth-program.js`. The component inventory is a local Langflow catalog snapshot. No Langflow source, runtime, or provider credentials are included.
