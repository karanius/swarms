# VoiceStudio engine and conversational-voice audit

Source revision: audited **main** `4d4cb0badf99c7518e3f4c69487df6e8bfeff43f` (read-only checkout). These findings do not establish that the latest packaged release contains every cited main-branch feature; the main audit compares the stable tag separately. No VoiceStudio code was executed, dependencies installed, weights downloaded, or speech quality benchmarked. Recommendations below select experiments, not winners.

## Decision

Use VoiceStudio as an engine/profile/production service, retaining our current verified audio chain as a comparison. For this Apple Silicon machine, prioritize **MLX Dia** for whole-script English dialogue and the **full VoxCPM2 engine** for controllable cloned/design voices. Add **MLX CSM** if stable reference-conditioned identity matters more than free-text delivery direction. A small Kokoro render is a useful installation smoke test, not evidence that it is the highest-quality conversational engine. The app/backend choice is covered by the main audit.

## “Lots of voices” needs four distinctions

1. **Designed-voice recipes:** the gallery generates combinations of gender, age, pitch and accent/dialect. Source describes about 51 featured archetypes plus hundreds of generated combinations. These are attribute recipes, not hundreds of separately trained or preinstalled human speaker models. A conversational category is a browsing label and preview script, not proof of conversational quality. [Archetype source](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/backend/core/archetypes.py#L1-L28), [category definitions](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/backend/core/archetypes.py#L84-L114).
2. **Gallery previews:** optional downloaded previews are fixed reference renderings. They are opt-in and deliberately never cloning reference audio. `/archetypes/{id}/use` stores a recipe; it does not make all engines/models resident. [Gallery implementation](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/backend/services/gallery.py#L1-L47), [archetype API](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/backend/api/routers/archetypes.py#L1-L23).
3. **Saved profiles:** records can contain designed attributes, a reference/transcript, or locked generated audio and a seed. They condition later speech, subject to the chosen engine's actual capability. [Profile resolver](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/backend/api/routers/audiobook.py#L258-L294).
4. **Compatibility aliases:** OpenAI-style names in `/v1/audio/voices` map to the same active engine's default voice; these are not supplied OpenAI voices or distinct local voice identities. [Exact alias construction](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/backend/api/routers/openai_compat.py#L1290-L1308).

Also distinguish engine package availability, downloaded model weights, successful model loading, and successful inference. The MLX documentation makes this explicit. [MLX setup and CSM preparation](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/docs/engines/mlx-audio.md#L16-L70).

## Emotion and conversation are not one capability

The code exposes machine-readable expression capabilities: graded emotion, written delivery direction, or none. Default OmniVoice offers limited attributes/reaction tags, not arbitrary “happy/sad” direction. Unrecognized bracket tags can be spoken aloud. IndexTTS has graded emotion; CosyVoice and full VoxCPM2 have written delivery direction. [Capability source](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/backend/services/expression.py#L10-L51), [engine-specific expressive guide](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/docs/expressive-speech.md#L1-L105), [advanced controls](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/docs/expressive-speech.md#L160-L218).

**Stories/longform largely orchestrates separate utterances, then joins them.** The generic synthesis callback forwards text, selected profile reference/transcript/instruction, speed and options; the render loop calls it separately for each chunk/span. No explicit accumulating audio/text conversation context is passed in those calls. Reusing a model or reference cache is not conversational-history conditioning. Thus cast selection, gaps, trimming, pauses and caching are real, but natural response-to-response prosody remains an experiment. Dia can instead receive a whole speaker-tagged dialogue in one model call; the current adapter still does not expose a documented persistent multi-turn session/history interface. [Synthesis callback](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/backend/api/routers/audiobook.py#L610-L705), [per-span render and joins](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/backend/services/audiobook.py#L468-L519), [Dia speaker-tag helper](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/backend/services/tts_backend.py#L2795-L2798).

## Model terms: do not treat the app's licence as voice clearance

- The repository explicitly marks **default OmniVoice weights as noncommercial/restricted**, distinguishes its Apache-2.0 code from CC-BY-NC weights, and identifies separate Higgs/Meta tokenizer terms. This is also corroborated by the pinned upstream card. It is not the safe default for a revenue pipeline. [Registry evidence](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/backend/config/model_licenses.json#L1-L40), [upstream card](https://huggingface.co/k2-fsa/OmniVoice/blob/c5fdb5ccb189668d56333f77ba2629f4cd7535f4/README.md).
- Dia, CSM, Kokoro, Qwen3 and VoxCPM2 have Apache-2.0 labels in the registry/model-card metadata, but VoiceStudio marks these selected distributions **unreviewed**, component closure incomplete, and inference/output terms unknown. Its `commercial_use: false` for an unreviewed entry is **not** the same finding as an upstream noncommercial prohibition. No blanket legal clearance is established here. [CSM entry](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/backend/config/model_licenses.json#L1687-L1718), [Dia entry](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/backend/config/model_licenses.json#L1828-L1865), [Dia conversion's own card](https://huggingface.co/mlx-community/Dia-1.6B/blob/de4fa8c178ca5cc4e9d884b55b03fcfaa0995162/README.md).
- IndexTTS has its own Bilibili terms and thresholds, not a blanket application grant. [Engine disclosure](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/docs/engines/indextts.md#L195-L209).

## Bounded quality experiment

Use the same short English dialogue in two conditions: (a) full dialogue in Dia with speaker tags; (b) stable male/female profiles rendered turn-by-turn with full VoxCPM2, then CSM if needed. Include interruptions, questions, calm-to-excited delivery, numbers/names and one repeated line. Compare direct output against our current F5 baseline, then apply the approved Money chain as a separate condition. VoiceStudio already masters some engines; full VoxCPM2 skips its 24 kHz mastering chain, so blindly stacking mastering/enhancement can worsen sound. [VoxCPM2 processing behavior](https://github.com/debpalash/VoiceStudio/blob/4d4cb0badf99c7518e3f4c69487df6e8bfeff43f/docs/engines/voxcpm2.md#L48-L69).

Record cold/warm load time, actual GPU/device evidence, RAM, elapsed generation/audio duration, output rate, exact engine/model revision/profile/settings, word omissions/repeats via independent transcription and listening, speaker identity across turns, emotion adherence, clipped/overlapping joins and loudness. Naturalness and emotional performance require listening; ASR alone is not a verdict. Install only the shortlisted models after their specific terms are reviewed. All runtime quality, latency and memory results remain unmeasured in this static audit.
